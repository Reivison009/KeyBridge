# Segurança do KeyBridge

## Downloads oficiais

Baixe versões do KeyBridge apenas pela [seção Releases deste repositório](https://github.com/Reivison009/KeyBridge/releases).

Antes de executar, verifique o nome do arquivo, a versão publicada e, quando fornecido, o hash SHA-256. Drivers e componentes necessários devem vir de fontes oficiais.

## Reportar vulnerabilidades

Evite publicar senhas, tokens, dados pessoais ou arquivos de log sem revisão. Para bugs que não envolvem segurança, [abra uma issue](https://github.com/Reivison009/KeyBridge/issues/new/choose).

Se identificar uma falha de segurança, procure o mantenedor pelo perfil do GitHub antes de divulgar detalhes exploráveis. Não envie segredos em issues públicas.

## Aviso sobre dependências

O projeto utiliza WebView2 e componentes relacionados a ViGEm. Verifique a procedência dos componentes redistribuídos e as respectivas condições de licença.
