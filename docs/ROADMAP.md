# Roadmap — KeyBridge Studio

Planejamento público do KeyBridge. Itens marcados como implementados foram **identificados no código e na interface enviada**, mas não equivalem a testes funcionais.

## Disponível na versão de desenvolvimento

- [x] Estrutura visual de janela nativa baseada em WebView2
- [x] Painel **Visão geral** com comandos de iniciar e parar
- [x] Editor de mapeamento com configuração JSON
- [x] Interface para criar e selecionar perfis
- [x] Área de diagnóstico, teste e logs
- [x] Instalador inicial de recursos incorporados no executável

## Próximas prioridades

- [ ] Publicar o primeiro EXE testado em **Releases**
- [ ] Adicionar capturas reais da interface em funcionamento
- [ ] Testar instalação limpa no Windows 10 e no Windows 11
- [ ] Documentar erros comuns de instalação e drivers
- [ ] Gerar hash SHA-256 do EXE em cada lançamento
- [ ] Implementar verificação de novas versões pela API do GitHub
- [ ] Implementar fluxo seguro de download e atualização com confirmação do usuário
- [ ] Criar uma demonstração em vídeo ou GIF

## Ideias futuras

- [ ] Importação e exportação fácil de perfis
- [ ] Assistente de configuração para iniciantes
- [ ] Melhorias de acessibilidade e navegação por teclado
