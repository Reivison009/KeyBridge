# Como publicar uma atualização

1. Gere e teste seu executável .exe.
2. Acesse https://github.com/Reivison009/KeyBridge/releases/new.
3. Crie uma tag nova, como `v1.0.0` ou `v1.1.0`.
4. Insira o título e as mudanças da versão.
5. Anexe o .exe em **Assets** e publique a release.
6. Confira https://github.com/Reivison009/KeyBridge/releases/latest.

O aplicativo pode consultar `https://api.github.com/repos/Reivison009/KeyBridge/releases/latest` para detectar novas versões, desde que essa função tenha sido implementada no EXE.
